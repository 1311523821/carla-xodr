实时诊断

对齐检查

还没跑。它把 xodr 的路面高度逆映射回扫描帧，和网格上的地板 逐点比 Δz —— 就是"车会不会悬空/陷进去"的预测量，约 3 秒，不需要服务端。

使用顺序

  1. 「加载数据」选扫描 FBX
  2. 描线 →「保存 traces.json」
  3. 「生成 xodr」离线：拟合 + 发射 + 校验
  4. 「对齐检查」离线，不需要 CARLA 起着
  5. 只有首次：「⎘ make import」复制命令去终端跑 → 回 UE 按 Play 它把 FBX 导成关卡，顺带烘一份 TM 采样表。命令开头那句 rm -f Import/*.json 是必须的：残留的包配置会让它跳过扫描新放的地图、 静默导回上一版
  6. 首次 / 换了扫描：「⎘ 标定」复制命令，在 CARLA 正加载着这张图时跑， 跑完回到第 3 步重做一遍 标定改的是扫描帧→world 的刚体，不重新生成，Δz 里还是旧偏移
  7. 「部署到 CARLA」→ 回 UE 重开一次 Play
  8. 以后只改描线/宽度：走 3 → 4 → 7 就够，不用再 make import、也不用重标定

操作提示

  • 左键空白处：给当前路加点
  • Shift+左键：强制加点（不去吸附顶点）
  • 左键已有顶点：选中并可拖动
  • Alt+左键线段上：在该段插入点
  • 滚轮缩放，中键/右键拖拽平移
  • Delete 删选中点，Ctrl+Z 撤销
  • 密点要先放大再点：底部状态栏右侧显示当前 px/m 与吸附半径
  • 裁剪拉条：顶端=场景 Z 最大，底端=Z 最小；往下拖依次剥掉屋顶、桌面、家具
  • 颜色：青=地板 暗=无地板 橙=净空不足
  • 高程不用管，服务端从扫描网格反推
